登录步骤
  1. 打开 github.com/settings/tokens，点 Generate new token
  2. 类型选 Fine-grained，Resource owner 选 3170687049-tech
  3. Repository access 选 Only select repositories，勾选 engine-notes-cms
  4. Permissions 里勾选 Contents: Read and write + Metadata: Read-only
  5. 点页面底部绿色 Generate token，复制 token（只显示一次！）
  6. 回到这里点 使用访问令牌登录，粘贴 token
